## Orden recomendado

<Steps>
  <Step title="Define el objetivo">
    Decide si necesitas consultar, analizar, automatizar o revisar una tarea ejecutada.
  </Step>
  <Step title="Elige la herramienta">
    Usa informes para revisar métricas, Boldy para consultas o tareas puntuales y automatizaciones para trabajos recurrentes o activados por eventos.
  </Step>
  <Step title="Revisa permisos y datos">
    Comprueba que el usuario y la automatización tengan acceso a los módulos necesarios.
  </Step>
  <Step title="Audita el resultado">
    Revisa historial, créditos, entradas usadas y acciones realizadas.
  </Step>
</Steps>

## Elegir herramienta

| Necesidad | Herramienta recomendada |
| :-- | :-- |
| Ver métricas consolidadas | Informes Power BI. |
| Preguntar por datos o estado | Boldy. |
| Analizar una situación con contexto | Boldy. |
| Ejecutar una tarea puntual | Boldy. |
| Programar una revisión periódica | Automatización. |

## Antes de empezar

La calidad de las respuestas depende de los datos disponibles. Mantén el catálogo, el stock, las órdenes y los partes al día antes de pedir análisis operativos.

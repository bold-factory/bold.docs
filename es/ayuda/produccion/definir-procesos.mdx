---
title: "Definir procesos"
description: "Crea procesos y asigna estaciones principales o auxiliares para ejecutar cada tipo de trabajo."
---

Los **procesos** son categorías reutilizables de trabajo productivo, como corte, montaje, soldadura, pintura o inspección.

Sirven para conectar una operación de receta con los recursos capaces de realizarla. Una operación indica qué proceso necesita; Bold puede proponer o limitar las estaciones de trabajo compatibles con ese proceso.

## Pasos a seguir

**Ruta:** **Fabricación > Procesos > Añadir nuevo tipo**

**Nombre:** usa un nombre corto y técnico que identifique la acción, como `Prensado`, `Embalaje`, `Perforación` o `Control de calidad`.

**Descripción:** detalla las tareas incluidas en el proceso. Por ejemplo, para `Unión de piezas` en el sector textil, puedes escribir `Confección y costura (remallado y pespunte plano) de los paneles frontales y traseros`.

## Asignar estaciones de trabajo al proceso

Después de crear el proceso, indica en qué estaciones puede ejecutarse. Asigna una o varias estaciones según corresponda.

**Ruta:** **Fabricación > Procesos > Proceso creado**

**+ Asignar estación**

**Estación de trabajo:** selecciona la máquina, línea o mesa donde se puede ejecutar el proceso. Por ejemplo, para `Soldadura`, selecciona **Puesto de soldadura TIG 02**.

<Tip>
  Si no aparece la estación que buscas, asegúrate de haberla creado previamente en **Preparar puestos y máquinas**.
</Tip>

**Eficiencia (%):** indica el ritmo de esta estación para el proceso. El `100 %` representa la velocidad estándar.

- **Si la estación trabaja al ritmo estándar:** déjalo en `100 %`.
- **Si trabaja más despacio:** reduce el porcentaje, por ejemplo a `80 %`. El sistema calculará tiempos de producción más largos cuando use esta estación.
- Si no necesitas este nivel de detalle, deja el valor por defecto: `100 %`.

**Tipo de estación (Principal o Auxiliar):** define el rol de esta máquina para el proceso.

- **Principal:** estación habitual para ejecutar el proceso. Puedes marcar varias como principales si, por ejemplo, tienes tres líneas equivalentes.
- **Auxiliar:** estación de reserva que se usa cuando las principales no están disponibles o no son adecuadas para un trabajo concreto.

<Note>
  **Ejemplo:** para un proceso de `Embotellado`, marca la `Línea automática 01` como **Principal** y la `Mesa de envasado manual` como **Auxiliar** para emergencias o lotes pequeños.
</Note>

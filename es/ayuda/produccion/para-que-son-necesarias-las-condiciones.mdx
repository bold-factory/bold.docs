---
title: "Adaptar la fabricación según variantes"
description: "Adapta operaciones, materiales, instrucciones y controles a cada variante fabricada."
---

Diseña una única ruta de fabricación para varias variantes de un mismo producto. En Bold, las **condiciones** muestran u ocultan operaciones, materiales, instrucciones o controles según las propiedades del artículo fabricado. Consulta [Recetas y versiones](/es/conceptos/fabricacion/recetas-y-versiones) para entender cómo se aplican las condiciones dentro de una receta.

Puedes aplicar condiciones en cuatro partes de la receta:

## Condicionar operaciones

Úsalas cuando una fase completa solo corresponda a determinadas variantes del artículo.

<Note>
  **Ejemplo:** la operación de _Pintura_ solo debe activarse si la propiedad _Acabado_ del producto requiere pintura. Si el cliente pide un cuadro de bicicleta con acabado en aluminio pulido, el sistema omite esta etapa.
</Note>

## Condicionar entradas

Úsalas cuando un material solo se consuma en algunas variantes del producto.

<Note>
  **Ejemplo:** configuras dos entradas de material en la misma operación: una para _Pintura roja_ y otra para _Pintura azul_. Al condicionar cada entrada a la propiedad _Color_, la OF solo cargará, mostrará y descontará del inventario el color que requiere esa bicicleta.
</Note>

## Condicionar pasos

Úsalas cuando una instrucción de trabajo solo deba mostrarse para determinadas variantes.

<Note>
  **Ejemplo:** en la etapa de ensamblaje, decides que solo las bicicletas con la propiedad **acabado premium** requieran un paso adicional de _Aplicación de cera protectora_. Para los modelos estándar, este paso no aparecerá en la pantalla del operario.
</Note>

## Condicionar controles

Úsalas para adaptar la inspección a la variante que se está fabricando.

<Note>
  **Ejemplo:** una prueba de presión de bomba de agua a 15 bares solo se activa si el **Modelo** es igual a `Profesional / Hostelería`. Así, el operario solo realiza esta prueba cuando pasa una máquina destinada a cafeterías.
</Note>

## Añadir una condición

**Origen (Propiedad / Contexto de la OF):** indica dónde debe buscar Bold el dato con el que evaluará la regla.

- **Propiedad:** característica del artículo, como el material, el color o el tamaño.
- **Contexto de la OF:** dato de una orden concreta, como el solicitante, la cantidad o las notas.

**Operador:** define cómo se compara el origen con el valor esperado, por ejemplo **Igual a**, **Distinto de**, **Contiene**, **Empieza por** o **Termina por**.

**Valor/Opción:** indica el valor que debe cumplir la condición. Por ejemplo: propiedad `Material`, operador `Igual a` y valor `Carbono`.

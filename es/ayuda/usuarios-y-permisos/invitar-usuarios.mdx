---
title: "Invitar usuarios"
description: "Da acceso a nuevas personas y asigna perfiles acordes a su trabajo."
---

Un usuario es la cuenta con la que una persona accede a Bold. Invita a cada persona que necesite acceso propio a la aplicación o a funciones administrativas.

<Info>
  Usuario y empleado no son lo mismo. El usuario controla acceso y permisos. El empleado representa a una persona operativa para turnos, trabajo, costes o asignaciones.
</Info>

## Antes de invitar

- Ten claro qué módulos debe usar la persona.
- Crea o revisa el perfil que le vas a asignar.
- Decide si debe vincularse a un empleado operativo.
- Evita compartir una cuenta entre varias personas si necesitas auditoría.

## Invitar a una persona

**Ruta:** **Panel de control > Usuarios > Invitar**

Campos a completar:

| Campo | Qué debes indicar |
| --- | --- |
| **Email** | Dirección de correo electrónico a la que se enviará la invitación. |
| **Empleado** | Empleado operativo que se vinculará a la cuenta. |
| **Rol** | Perfil de permisos que se aplicará al usuario. |

En **Empleado**, elige una de estas opciones:

- **Asociar a empleado existente:** si la persona ya está registrada como empleado.

- **Crear nuevo empleado:** si todavía no está registrada.

Si asocias uno existente, selecciónalo en **Empleado**. Si creas uno nuevo, completa **Nombre**, **Apellidos** y, si procede, **Código de empleado**.

El perfil asignado determina las pantallas y acciones a las que podrá acceder el usuario.

## Vincular usuario y empleado

Vincula el usuario con un empleado cuando sus acciones deban asociarse a una persona operativa. Esto importa en planta, turnos, costes, asignaciones y tareas.

Casos habituales:

- Un empleado que registra trabajo desde una tableta.
- Un responsable que actúa en nombre de un empleado en un flujo operativo.
- Una cuenta que necesita consultar datos, pero no registrar trabajo. En este caso puede no necesitar vínculo con empleado.

## Recomendaciones

| Situación | Recomendación |
| --- | --- |
| Nuevo responsable de almacén | Asigna permisos de lectura y escritura de almacén. |
| Operario de planta | Asigna permisos de trabajo de producción y vínculo con empleado. |
| Planificador | Asigna lectura y escritura de planificación, compras y producción según proceso. |
| Integración técnica | Usa una credencial técnica gestionada por un administrador en vez de una cuenta personal. |
| Usuario temporal | Usa perfiles mínimos y define una fecha de revisión del acceso. |

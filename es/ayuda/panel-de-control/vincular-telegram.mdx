Vincula tu cuenta de Telegram para conversar con Boldy desde el bot de tu empresa. La vinculación es personal y asocia tu usuario de Bold con una única identidad de Telegram.

## Antes de empezar

- Telegram debe estar disponible para tu empresa. Si **Mi cuenta** indica que no lo está, contacta con el administrador de tu empresa o con Bold.
- Inicia el proceso con tu propio usuario de Bold y abre el enlace con la cuenta de Telegram que quieras vincular.
- Para enviar tareas a Boldy necesitas permiso para iniciar tareas con agentes. Para adjuntar archivos también necesitas permiso para subir archivos.

## Vincular la cuenta

**Ruta:** **Panel de control > Mi cuenta**

<Steps>
  <Step title="Inicia la vinculación">
    En la sección **Telegram**, comprueba el nombre del bot de tu empresa y pulsa **Vincular Telegram**.
  </Step>
  <Step title="Abre Telegram">
    Pulsa **Abrir Telegram**. Se abrirá una conversación privada con el bot mediante un enlace que incluye el código de vinculación.
  </Step>
  <Step title="Confirma con el bot">
    Si Telegram muestra el botón **Iniciar** o **Start**, púlsalo para enviar el comando al bot. El bot confirmará que la cuenta ha quedado vinculada.
  </Step>
  <Step title="Comprueba el estado en Bold">
    Vuelve a **Mi cuenta**. La sección mostrará **Vinculado como** seguido de tu alias de Telegram o de la identidad verificada.
  </Step>
</Steps>

<Note>
  El enlace muestra su fecha y hora de caducidad. Si caduca antes de completar el proceso, vuelve a **Mi cuenta** y pulsa de nuevo **Vincular Telegram** para generar otro.
</Note>

## Conversar con Boldy

Después de vincular la cuenta, pulsa **Abrir conversación** o abre directamente el bot en Telegram. Envía un mensaje para iniciar una tarea privada con Boldy.

La conversación permanece en Telegram. Puedes consultar la tarea, su actividad y su resultado en **Smart Factory > Tareas**, pero debes responder desde el chat de Telegram donde la iniciaste.

Boldy acepta texto, imágenes, documentos y audio compatibles. Los archivos pueden ocupar hasta 20 MB.

## Desvincular Telegram

En **Panel de control > Mi cuenta**, pulsa **Desvincular** y confirma la acción. Dejarás de poder conversar con Boldy desde esa identidad de Telegram, pero podrás volver a vincularla más adelante.

La desvinculación afecta solo a tu identidad. No desconecta ni modifica el bot configurado para la empresa.

## Problemas habituales

| Problema | Qué hacer |
| --- | --- |
| Telegram no está disponible para tu empresa | Pide al administrador que confirme la disponibilidad del canal o contacta con Bold. |
| El enlace ha caducado | Vuelve a **Mi cuenta** y pulsa **Vincular Telegram** para generar otro. |
| El bot indica que el código no es válido | Inicia de nuevo la vinculación. No reutilices un enlace anterior. |
| La identidad de Telegram ya está vinculada | Desvincúlala del usuario de Bold anterior antes de intentar asociarla a otro. |
| El bot indica que has perdido el acceso | Revisa que tu usuario siga activo y tenga permiso para iniciar tareas con agentes. |
| No puedes adjuntar archivos | Revisa el permiso para subir archivos y que el archivo sea compatible y no supere 20 MB. |

title: "Administrar archivos"
description: "Consulta y administra documentos adjuntos usados en Bold."
---

Usa **Gestión de archivos** para consultar los documentos y adjuntos almacenados en Bold. Pueden estar vinculados a operaciones, controles, partes de trabajo, automatizaciones, importaciones u otros registros.

## Qué guarda Bold de cada archivo

| Campo | Uso |
| --- | --- |
| Nombre | Nombre con el que se guardó el archivo. |
| Tipo y tamaño | Formato detectado y espacio que ocupa, si está disponible. |
| Contexto | Etiquetas registradas para el archivo. Las etiquetas de algunos registros permiten abrirlos desde el listado. «Sin contexto registrado» no garantiza que el archivo no esté referenciado en una nota; el etiquetado puede estar pendiente de procesamiento. |
| URI de lectura | Enlace seguro para abrir o descargar el archivo. |
| Gestión | Indica si Bold gestiona el archivo. Los archivos gestionados por Bold no se pueden eliminar desde el listado general. |
| Auditoría | Fecha de creación y usuario que creó el archivo. |

## Archivos enlazados en notas e instrucciones

Cuando guardas un enlace a un archivo de Bold en un campo que admite Markdown, Bold añade automáticamente una etiqueta con el registro que lo usa. Esto se aplica a las notas de pedidos y líneas de compra y venta, partes de trabajo, planes preventivos, órdenes y peticiones de fabricación, así como a las instrucciones de operaciones y pasos de receta. Desde el contexto del listado puedes abrir ese registro.

La asociación se actualiza en segundo plano después de guardar el registro. Si retiras el enlace o eliminas el registro, su etiqueta de uso desaparece tras el procesamiento. Un archivo puede tener varias etiquetas si se utiliza en varios lugares. Los enlaces que ya estaban guardados antes de esta función se asociarán al modificar y guardar el campo que los contiene.

La etiqueta indica dónde se usa el archivo. No convierte por sí sola el archivo en **gestionado por Bold** ni impide eliminarlo desde el listado.

## Formatos admitidos

Bold valida la extensión y el contenido real del archivo. Entre los formatos admitidos están:

| Tipo | Extensiones |
| --- | --- |
| PDF | `.pdf` |
| Imágenes | `.jpg`, `.jpeg`, `.png`, `.webp` |
| Texto y datos | `.txt`, `.md`, `.markdown`, `.csv` |
| Word | `.doc`, `.docx`, `.docm` |
| Excel | `.xls`, `.xlsx`, `.xlsm`, `.xlsb` |
| Comprimidos | `.zip` |

<Warning>
  Si cambias la extensión de un archivo sin cambiar su contenido real, Bold puede rechazarlo por discrepancia de tipo.
</Warning>

## Revisar archivos

<Steps>
  <Step title="Abre Gestión de archivos">
    Entra en **Panel de control > Gestión de archivos**.
  </Step>
  <Step title="Busca el archivo">
    Filtra por nombre, fecha o usuario cuando aplique.
  </Step>
  <Step title="Revisa metadatos">
    Comprueba el tipo, tamaño, contexto y si Bold gestiona el archivo.
  </Step>
  <Step title="Abre o descarga">
    Usa el enlace de lectura para revisar el contenido.
  </Step>
  <Step title="Elimina solo si procede">
    Borra archivos solo cuando tengas claro que no son necesarios para auditoría, evidencias o procesos activos.
  </Step>
</Steps>

## Buenas prácticas

- Usa nombres descriptivos antes de subir archivos.
- No borres archivos usados como evidencias de calidad, mantenimiento o automatizaciones sin revisar el proceso.
- Usa Excel/CSV para importaciones y adjuntos estructurados.
- Usa PDF o imágenes para evidencias que no deben cambiar.

## Problemas habituales

| Problema | Qué revisar |
| --- | --- |
| El archivo no se acepta | Revisa extensión, tipo real de archivo y si está dañado. |
| No puedes eliminarlo | Puede faltar permiso o estar gestionado por Bold. |
| No encuentras el archivo | Busca por etiquetas o por el registro que lo generó. |
| El enlace no abre | Revisa permisos y si la URI de lectura sigue vigente. |

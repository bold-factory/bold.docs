---
title: "Diseñar perfiles por responsabilidad"
description: "Agrupa permisos por trabajo real antes de invitar usuarios o ampliar acceso."
---

Diseña perfiles por responsabilidad para que cada persona vea y haga solo lo necesario. Este flujo ayuda a evitar permisos demasiado amplios o perfiles duplicados por cada usuario.

### **Diferencia clave antes de empezar**

- **Usuario:** es la cuenta que se usa para iniciar sesión en el ordenador o la tablet (ej: `oficina@empresa.com` o `planta-tablet@empresa.com`).
- **Empleado:** es la persona física que realiza el trabajo y ficha desde la tablet en modo trabajo.
- **Rol:** es la etiqueta de permisos que le aplicas al **usuario**.

## Antes de crear perfiles

Haz una lista de responsabilidades reales:

- administración de empresa;
- compras;
- ventas;
- almacén;
- planificación;
- producción;
- mantenimiento;
- costes;
- informes y análisis;
- integraciones.

## Crear perfiles

**Ruta: Panel de control > Roles**

<Steps>
  <Step title="Crea perfiles reutilizables">
    **Nombre:** Pon un nombre claro que represente una función real en la fábrica. Usa perfiles como almacén, compras, producción o administración cuando varias personas compartan permisos.

    **Descripción:** Explica brevemente qué abarca este perfil.
  </Step>
  <Step title="Configura los permisos">
    Selecciona qué acciones puede realizar este rol (Lectura, Creación, Edición, Eliminación) en cada módulo (_Fabricación, Almacén, Planificación, Mantenimiento, Personal, Panel de Control_).
  </Step>
  <Step title="Haz clic en Guardar. ">
    Estos perfiles nos servirán para asignar ciertos permisos a los usuarios registrados.
  </Step>
</Steps>

## Revisión periódica

| Revisión | Cuándo hacerla |
| --- | --- |
| Usuarios inactivos | Cada cierre de mes o salida de personal. |
| Permisos administrativos | Cada cambio de responsable. |
| Nuevos módulos | Antes de activar el módulo para más usuarios. |
| Integraciones | Antes de crear claves de integración o avisos externos. |
| Auditoría | Cuando investigues cambios sensibles. |

<Warning>
  Evita usar un perfil administrador para trabajo diario. Reserva permisos amplios para tareas de configuración y soporte.
</Warning>

---
title: "Diseñar perfiles por responsabilidad"
description: "Agrupa permisos por trabajo real antes de invitar usuarios o ampliar acceso."
---

Diseña perfiles por responsabilidad para que cada persona acceda solo a las áreas y acciones que necesita. Reutilizar perfiles evita duplicar la configuración para cada usuario.

## Diferencias entre usuario, empleado y perfil

- **Usuario:** cuenta que inicia sesión en el ordenador o la tableta, por ejemplo `oficina@empresa.com`.
- **Empleado:** persona cuyo trabajo o presencia se registra en el modo de trabajo.
- **Perfil:** conjunto de permisos que asignas a un usuario. En la interfaz, los perfiles se configuran desde **Roles**.

## Antes de crear perfiles

Haz una lista de responsabilidades reales:

- administración de empresa;
- compras;
- ventas;
- almacén;
- planificación;
- fabricación;
- mantenimiento;
- costes;
- informes y análisis;
- integraciones.

## Crear perfiles

**Ruta:** **Panel de control > Roles**

<Steps>
  <Step title="Crea perfiles reutilizables">
    En **Nombre**, indica una función real de la fábrica. Usa perfiles como `Almacén`, `Compras`, `Fabricación` o `Administración` cuando varias personas compartan permisos.

    En **Descripción**, explica brevemente qué abarca el perfil.
  </Step>
  <Step title="Configura los permisos">
    Selecciona los permisos que necesita el perfil en cada módulo. Las acciones se muestran con su nombre real, como **Ver**, **Editar**, **Activar**, **Trabajar** o **Secuenciar**, según el área.
  </Step>
  <Step title="Guarda el perfil">
    Pulsa **Guardar**. Después podrás asignar el perfil a los usuarios registrados desde **Panel de control > Usuarios**.
  </Step>
</Steps>

## Revisión periódica

| Revisión | Cuándo hacerla |
| --- | --- |
| Usuarios inactivos | Cada cierre de mes o salida de personal. |
| Permisos administrativos | Cada cambio de responsable. |
| Nuevos módulos | Antes de activar el módulo para más usuarios. |
| Integraciones | Antes de crear claves de integración o avisos externos. |
| Auditoría | Cuando investigues cambios sensibles. |

<Warning>
  Evita usar un perfil administrador para trabajo diario. Reserva permisos amplios para tareas de configuración y soporte.
</Warning>

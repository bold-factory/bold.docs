## Usuario y empleado

Un usuario controla acceso. Un empleado representa trabajo operativo. Pueden estar relacionados, pero no son el mismo concepto.

Usa un usuario para entrar en Bold y recibir permisos. Usa un empleado para registrar mano de obra, calcular costes o relacionar trabajo operativo. Consulta [Usuarios, perfiles y permisos](/es/conceptos/panel-de-control/usuarios-roles-y-permisos) para la parte de acceso.

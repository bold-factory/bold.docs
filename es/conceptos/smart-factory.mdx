Smart Factory reúne las herramientas para analizar datos, consultar a Boldy, delegar tareas y ejecutar trabajos automáticos.

## Cuándo usar cada herramienta

| Necesidad | Usa |
| --- | --- |
| Analizar tendencias o comparar periodos | **Informes**. |
| Ver el estado operativo de fabricación | **Cuadros de mando**. |
| Preguntar o explorar información en conversación | **Boldy**. |
| Delegar un trabajo puntual y revisar su historial | **Tareas**. |
| Repetir un trabajo con una configuración estable | **Automatizaciones**. |

Una automatización no es un asistente independiente. Conserva la configuración reutilizable del trabajo y cada ejecución crea una tarea con su propio historial y resultado.

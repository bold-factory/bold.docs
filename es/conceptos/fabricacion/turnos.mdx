El **horario de fabricación** define las franjas semanales en las que la fábrica puede ejecutar operaciones.

Actualmente existe un único horario global para fabricación. No puedes definir un horario distinto por área, línea, estación o recurso.

## Turnos de fabricación frente a turnos de personal

| Concepto | Uso |
| --- | --- |
| Horario de fabricación | Define las franjas productivas globales que usan planificación y secuenciación. |
| Turno de personal | Define jornadas, ciclos y disponibilidad de empleados. |

Pueden estar alineados, pero resuelven preguntas distintas. Fabricación necesita un calendario productivo global. Personal necesita saber cuándo se espera que trabaje cada empleado.

## Cómo se define

| Dato | Uso |
| --- | --- |
| Día de la semana | Indica cuándo se repite la franja. |
| Hora de inicio | Marca el comienzo del tiempo productivo. |
| Hora de fin | Marca el final del tiempo productivo. Puede caer en el día siguiente. |

Puedes configurar varias franjas para un mismo día. El tiempo que queda fuera de ellas se considera no laborable para la planificación de fabricación.

El horario no admite cierres ni excepciones por fecha. Usa los turnos y calendarios de Personal para planificar la disponibilidad de empleados, no para cambiar este horario global.

## Uso en secuenciación

La secuenciación usa el horario para proponer operaciones dentro de franjas productivas. Si no refleja la realidad de la fábrica, una orden puede parecer viable en fecha aunque la planta esté cerrada.

Revisa el horario cuando veas operaciones fuera de jornada o capacidad disponible que no coincide con la fábrica.

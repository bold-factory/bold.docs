Los **recursos** representan la capacidad física o técnica necesaria para ejecutar operaciones.

Pueden ser áreas, estaciones, máquinas, herramientas, equipos o características requeridas por una operación.

Para ver cómo se modelan útiles y requisitos técnicos reutilizables, consulta [Herramientas y características](/es/conceptos/fabricacion/herramientas-y-caracteristicas).

## Entidades

| Concepto | Uso |
| --- | --- |
| Área | Agrupa estaciones o zonas productivas. |
| Estación de trabajo | Lugar donde se ejecuta una operación. |
| Herramienta | Recurso seleccionable para una operación. |
| Característica | Requisito que permite elegir herramientas compatibles. |
| Tipo de capacidad de estación | Define si una estación limita la planificación. |

## Estaciones y procesos

Una estación indica dónde puede ejecutarse trabajo. Un proceso describe el tipo de trabajo y vive como concepto propio en [Procesos](/es/conceptos/fabricacion/procesos).

Ejemplo: el proceso **Corte** puede ejecutarse en las estaciones **Sierra 1** y **Sierra 2**.

## Herramientas y características

Usa características cuando una operación exige una condición técnica. Las herramientas que cumplen esa característica pueden seleccionarse durante planificación o ejecución.

| Necesidad | Modelo |
| --- | --- |
| Cualquier operario puede usar una estación | Estación sin herramienta requerida. |
| La operación necesita útil específico | Herramienta con característica. |
| La diferencia solo es una nota | Paso o instrucción, no recurso. |

## Capacidad

La capacidad finita o infinita se configura en las estaciones. Una estación finita solo puede atender una operación a la vez; una estación infinita no bloquea otras operaciones en la misma franja.

Las herramientas se tratan como recursos finitos. Los empleados solo entran como recursos limitantes cuando activas esa opción en el plan de producción.

La capacidad se interpreta junto con el horario de fabricación, los procesos compatibles y la duración prevista. Si falta cualquiera de esos datos, la secuenciación puede proponer fechas incompletas o recursos incorrectos.

## Relación con ubicaciones

Una estación puede relacionarse con ubicaciones de planta si necesitas consumir o producir material cerca del recurso.

Esto es útil cuando el stock se mueve físicamente a una línea, célula o zona de trabajo antes de ejecutarse.

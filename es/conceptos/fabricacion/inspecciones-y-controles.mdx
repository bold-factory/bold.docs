Las **inspecciones y controles** capturan evidencias, validaciones y resultados de calidad. Sus reglas cambian según el área.

Úsalos cuando una comprobación deba quedar vinculada a una operación, artículo, recepción o movimiento real.

## Dónde aparecen

| Área | Qué valida |
| --- | --- |
| Producción | Controles obligatorios de operación al inicio, durante el avance o al final. |
| Catálogo | Inspecciones asociadas al artículo para definir qué revisar. |
| Almacén | Inspecciones obligatorias u opcionales de recepción. |
| Mantenimiento | Acciones opcionales con resultado dentro de un parte de trabajo. |

No todos los controles son de calidad estricta. Algunos registran confirmaciones operativas, fotos, medidas o archivos que explican cómo se hizo el trabajo.

## Tipos de resultado

| Tipo | Cuándo usarlo |
| --- | --- |
| Confirmación | El operario debe confirmar que una acción se hizo. |
| Sí/no | Necesitas un resultado aceptado o rechazado. |
| Número | Quieres registrar una medida. |
| Texto | Necesitas una observación libre. |
| Imagen | Debe quedar evidencia visual. |
| Archivo | Debe adjuntarse un documento o prueba externa. |

Configura el tipo según el dato que necesitas conservar.

## Momento de ejecución

| Momento | Efecto |
| --- | --- |
| Al inicio | Bloquea el arranque hasta completar la validación. |
| Por unidad o progreso | Exige los registros correspondientes al avance. |
| Al final | Bloquea el cierre hasta completar la comprobación. |

En fabricación, todos los controles configurados son obligatorios. Si el operario no puede iniciar o finalizar, revisa qué control falta y si requiere archivo, foto, valor o confirmación.

## Inspecciones de recepción

Una recepción puede incluir inspecciones obligatorias u opcionales. Solo las obligatorias bloquean la recepción mientras estén pendientes.

Después de recibir, la recepción y sus inspecciones quedan protegidas para conservar el historial.

## Acciones de mantenimiento

Las acciones de un parte de mantenimiento son opcionales: el parte puede completarse aunque alguna quede pendiente. Si completas una acción, su resultado debe respetar el tipo configurado.

También puedes configurar una acción de **Selección** con respuestas cerradas o una acción de **Firma** para que el técnico dibuje su firma. La firma se guarda como imagen y conserva el tipo de resultado **Firma** en el parte.

## Relación con costes y trazabilidad

Los controles no calculan coste por sí solos, pero explican desviaciones, rechazos, reprocesos o bloqueos.

Cuando una inspección genera rechazo, pausa o ajuste, conecta el resultado con [Controles, consumos y pausas](/es/conceptos/fabricacion/controles-consumos-y-pausas), [Stock y movimientos](/es/conceptos/almacen/stock-y-movimientos) o [Coste teórico vs coste real](/es/conceptos/costes/coste-teorico-vs-real).

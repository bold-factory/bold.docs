Una **tarea** es un trabajo puntual que delegas a Boldy. Puede iniciarse manualmente, desde una automatización o mediante una integración.

La tarea conserva instrucciones, mensajes, archivos adjuntos, herramientas usadas, aclaraciones, resultado y créditos consumidos.

## Configuración de una tarea puntual

| Opción | Uso |
| --- | --- |
| Instrucciones | Describen el resultado que necesitas y el contexto del trabajo. |
| Nivel de inteligencia | Ajusta la capacidad de razonamiento y el consumo esperado. |
| Visibilidad | Decide quién puede consultar la tarea. |
| Modo de trabajo | Decide si Boldy puede realizar cambios o solo consultar datos. |
| Archivos y audio | Añaden contexto a las instrucciones. |

### Visibilidad

| Opción | Quién puede verla |
| --- | --- |
| **Solo para mí** | El usuario que creó la tarea. |
| **Compartida** | Otros usuarios con acceso a las tareas de Smart Factory. |

El propietario puede continuar su tarea. Para intervenir en una tarea compartida de otra persona se necesita permiso para administrar todas las tareas.

### Modo de trabajo

| Opción | Comportamiento |
| --- | --- |
| **Solo lectura** | Boldy puede consultar y analizar, pero no modificar datos. |
| **Permitir cambios** | Boldy puede usar las acciones permitidas durante la tarea. |

El modo **Permitir cambios** no evita los controles de acceso. Boldy solo puede ejecutar acciones para las que la tarea tenga permiso.

## Estados

| Estado | Qué hacer |
| --- | --- |
| **Pendiente** | Espera a que empiece el procesamiento. |
| **En ejecución** | Boldy está trabajando. |
| **Requiere acción** | Responde a la aclaración o decisión pendiente. |
| **Completada** | Revisa el resultado. |
| **Fallida** | Revisa el error y decide si debes iniciar otra tarea. |

Las tareas caducan tras 28 días de inactividad. Si necesitas retomar una tarea caducada, crea otra con el contexto necesario.

## Canal de origen

Una tarea iniciada desde un canal de mensajería conserva ese canal. Puedes consultar la actividad y el resultado en la web, pero debes responder desde la misma conversación externa.

Consulta [Canales e identidades relacionadas](/es/conceptos/panel-de-control/identidades-relacionadas) para entender cómo Bold reconoce al usuario que conversa desde otro canal.

## Cómo escribir las instrucciones

Incluye el objetivo, el periodo, los registros relevantes, los límites y el formato esperado.

| Caso | Ejemplo |
| --- | --- |
| Resumen operativo | `Resume las OF en progreso con retrasos y próximos pasos.` |
| Revisión de mantenimiento | `Revisa los partes abiertos del activo ENV-01 y destaca los que requieren acción.` |
| Validación de datos | `Comprueba los archivos adjuntos e identifica inconsistencias antes de importarlos.` |

<Warning>
  Revisa las tareas críticas antes de usar su resultado para tomar decisiones o cambiar datos operativos.
</Warning>

Las **claves de integración** permiten que un sistema externo se autentique en Bold. Los **avisos externos** notifican a otros sistemas cuando ocurre un evento.

## Claves de integración

Actualmente, una clave de integración tiene acceso administrativo amplio a los datos y acciones del tenant. No puedes asignarle permisos ni alcances configurables.

<Warning>
  Quien obtenga la clave puede actuar con privilegios elevados sobre el tenant. No la incluyas en código cliente, mensajes, documentación pública ni registros de aplicación.
</Warning>

Aplica estas medidas:

- crea una clave distinta para cada sistema externo;
- guárdala en un gestor de secretos;
- limita quién puede verla en el sistema que la utiliza;
- revócala si deja de usarse o sospechas que se ha expuesto;
- rota la clave de forma coordinada con la integración.

La clave completa se muestra al crearla. Conserva una copia segura en ese momento.

## Avisos externos

| Concepto | Uso |
| --- | --- |
| Evento | Cambio relevante en Bold, como un cambio de stock, pedido, orden o parte. |
| Suscripción | Configuración que decide qué eventos se envían y a qué destino. |
| Entrega | Petición HTTP enviada al sistema externo. |

Usa avisos externos cuando otro sistema necesite reaccionar a cambios de catálogo, stock, pedidos, fabricación o mantenimiento.

<Tip>
  Para integraciones críticas, combina los avisos externos con una reconciliación periódica mediante la API. La reconciliación permite detectar diferencias aunque una entrega falle.
</Tip>

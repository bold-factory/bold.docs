La **auditoría** muestra los eventos registrados para una entidad. Los **eventos** explican qué ocurrió en Bold para sincronizar módulos, notificaciones, avisos externos y automatizaciones.

Ambos ayudan a depurar incidencias, revisar integraciones y proteger la trazabilidad.

## Auditoría

La auditoría permite revisar el historial de eventos de una entidad de negocio.

| Dato | Para qué sirve |
| --- | --- |
| Evento | Identifica el hecho registrado. |
| Autor | Indica quién originó el evento cuando está disponible. |
| Contenido | Muestra el contenido serializado del evento. |
| Fecha | Sitúa el evento en el tiempo. |

La vista no calcula una diferencia entre valores anteriores y posteriores. Usa la secuencia y el contenido de los eventos para reconstruir qué ocurrió sobre la entidad consultada.

## Eventos

Un evento comunica que algo ocurrió. Puede alimentar proyecciones internas, notificaciones, avisos externos o automatizaciones.

| Uso | Ejemplo |
| --- | --- |
| Sincronización interna | Una recepción actualiza stock y planificación. |
| Notificación | Un usuario recibe aviso por un cambio relevante. |
| Aviso externo | Un sistema externo recibe el evento. |
| Automatización | Se crea una tarea cuando el evento cumple una condición. |

No todos los cambios generan el mismo tipo de evento público. Revisa la referencia de desarrolladores para integraciones externas.

## Relación con notificaciones y avisos externos

Las [Notificaciones](/es/conceptos/panel-de-control/notificaciones) usan eventos para avisar dentro de la aplicación o por correo electrónico.

Los [avisos externos](/es/conceptos/panel-de-control/claves-de-integracion-y-avisos-externos) envían eventos a sistemas externos. Conserva los datos necesarios para investigar entregas fallidas o discrepancias.

## Relación con automatizaciones

Las automatizaciones por evento crean tareas cuando el evento seleccionado y su condición coinciden.

Antes de activar una automatización crítica, verifica:

- qué evento la dispara;
- qué versión del evento usa;
- qué condición filtra ejecuciones;
- qué permisos tiene la automatización;
- quién revisará las tareas generadas.

## Buenas prácticas

- Usa usuarios nominales para mantener trazabilidad.
- Evita compartir claves de integración entre integraciones distintas.
- Revisa auditoría antes de corregir stock o pedidos manualmente.
- Documenta automatizaciones por evento que afecten procesos críticos.
- Mantén avisos externos con destinos observables y reintentos controlados.

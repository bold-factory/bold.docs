Un **parte de trabajo** registra una intervención de mantenimiento sobre un activo.

Explica qué ocurrió, por qué ocurrió, quién intervino, cuánto tiempo se dedicó, qué acciones se completaron y qué materiales se consumieron.

## Qué contiene

| Dato | Uso |
| --- | --- |
| Activo | Equipo o espacio físico intervenido. |
| Tipo | Correctivo o preventivo. |
| Causa | Motivo principal y posibles causas auxiliares. |
| Acciones | Tareas o comprobaciones realizadas. |
| Tiempos | Mano de obra por empleado. |
| Materiales | Repuestos o consumibles usados. |
| Comentarios | Observaciones con fecha y autor añadidas durante el trabajo. |
| Estado | Situación del parte. |

## Estados habituales

| Estado | Significado |
| --- | --- |
| Pendiente | El parte existe, pero no tiene tiempo activo. |
| En progreso | Hay un registro de tiempo activo. |
| Pausado | Hubo trabajo, pero no hay tiempo activo. |
| Completado | La intervención termina y queda protegida mientras mantenga este estado. |
| Cancelado | El parte se cierra sin completarse y conserva los tiempos ya registrados. |

## Materiales y trazabilidad

Los materiales consumidos vinculan mantenimiento con almacén y costes. Si el artículo trabaja con lotes, registra el lote real usado.

El coste del parte depende de materiales, lotes, cantidades, tiempo y coste horario de empleados.

## Partes preventivos

Una programación preventiva puede generar partes automáticamente o lanzarse manualmente. El parte generado sigue siendo la ejecución real; la programación solo define cuándo debe aparecer. Desde el parte puedes abrir la programación que lo generó, aunque se haya eliminado.

## Comentarios

Los comentarios dejan constancia de lo ocurrido durante la intervención. Cada comentario guarda la fecha, el usuario y, desde el modo de trabajo, el empleado activo. Admiten formato y archivos adjuntos.

- Puedes añadirlos desde **Mantenimiento > Partes** y desde el modo de trabajo, también en partes completados.
- No se pueden editar. Solo se pueden eliminar desde **Mantenimiento > Partes**.
- No se pueden añadir ni eliminar en partes cancelados.

Los comentarios son distintos de las notas del parte, que describen el trabajo previsto.

## Deshacer una finalización

Puedes usar **Deshacer finalización** sobre un parte completado. El parte vuelve a estar abierto y permite añadir tiempos, materiales y acciones.

Si el parte ya tenía tiempos terminados, vuelve a **Pausado**. Si no tenía tiempos, vuelve a **Pendiente**. Un parte cancelado no se puede reabrir de esta forma.

Puedes completar el parte aunque queden acciones pendientes, salvo que alguna sea obligatoria. Si completas una acción, debes registrar un resultado válido para su tipo.

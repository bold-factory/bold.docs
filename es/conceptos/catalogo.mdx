## Cómo encajan

| Concepto | Uso |
| --- | --- |
| Familia | Agrupación comercial o técnica que reúne artículos relacionados y define sus propiedades requeridas. |
| Artículo | Elemento físico único. Bold controla sobre él stock, compras, ventas, fabricación y costes. |
| Propiedad | Atributo reutilizable que diferencia variantes, como color, medida, material o acabado. |
| Valor de propiedad | Valor concreto que describe una variante dentro de una familia. |
| Unidad de medida | Forma en la que se cuantifican stock, pedidos, consumos y producción. |
| Coproducto | Salida adicional generada durante una fabricación. |

La familia organiza las variantes. El artículo es la referencia operativa con stock, pedidos, fabricación y costes propios. Las propiedades explican las diferencias entre artículos de una misma familia.

Consulta las páginas de este grupo para ver las reglas de información requerida, consolidación, unidades y modelado de variantes.

## Relación con otras áreas

| Módulo | Dependencia del catálogo |
| --- | --- |
| Planificación | Usa artículos, plazos, punto de pedido y origen de aprovisionamiento. |
| Almacén | El stock se registra por artículo, ubicación y lote opcional. Los lotes se gestionan desde almacén cuando necesitas trazabilidad. |
| Fabricación | Las recetas pueden vincularse a familias o artículos y producen o consumen artículos. |
| Costes | El coste se calcula sobre artículos, lotes, consumos, producción y valor de inventario. |
| Integraciones | Relacionan el artículo operativo con referencias de otros sistemas. |

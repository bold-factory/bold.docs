A **package** represents a movable physical unit in the warehouse, such as a pallet, box, trolley, sack, container or kit.

A package does not replace stock. It groups stock lines so your team can identify and move a complete physical unit.

## What it contains

| Data | Use |
| --- | --- |
| Code | Identifies the package through a label, QR code or search. |
| Container type | Indicates its physical format: box, pallet, trolley or similar. |
| Current location | Where the package is. |
| Contents | Included items, lots and quantities. |
| Status | Indicates whether the package is active or inactive. |

A package can contain several items and lots if they physically travel together and your team can identify them without ambiguity.

## When to use packages

Use packages when:

- you move grouped material;
- you need to print labels per physical unit;
- you prepare kits, pallets or boxes for production or shipment;
- you want to know the location of an entire container.

Do not use packages for every unit if your team operates with loose quantities. Adding unnecessary packages increases records without improving traceability.

## Relationship with locations

A package has a current location. When it moves, its contents are considered associated with the new location.

If you remove part of the contents, the package retains what remains. Empty is not a package status: you view its contents and active or inactive status separately.

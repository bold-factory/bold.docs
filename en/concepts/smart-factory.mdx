## When to use each tool

| Requirement | Use |
| --- | --- |
| Analyze trends or compare periods | **Reports**. |
| View manufacturing operational status | **Dashboards**. |
| Ask questions or explore information in conversation | **Boldy**. |
| Delegate one-off work and review its history | **Tasks**. |
| Repeat work with a stable configuration | **Automations**. |

An automation is not an independent assistant. It preserves reusable work configuration, and each run creates a task with its own history and result.

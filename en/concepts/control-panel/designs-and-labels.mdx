**Designs** define output formats for documents, labels or identifiers used by the team on the shop floor, in the warehouse or in administration.

## Concepts

| Concept | Use |
| --- | --- |
| Design | Reusable template to generate an output. |
| Label | Printable format to identify items, lots, packages, workstations or other supported objects. |
| Dynamic value | Bold data inserted in the design. |
| QR code or barcode | Scannable representation to speed up identification. |

## Design rules

A template should be readable at its actual print size and contain only the information needed to identify the object.

Before using a template in bulk, download a sample and test it with the reader the team will use.

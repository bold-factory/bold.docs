Data and files cover imports, attached documents, evidence and maintenance of information used by several modules.

## Imports

Imports are used to upload master or historical data. Before importing, validate codes, units, relationships and duplicates.

| Risk | Required review |
| --- | --- |
| Duplicate codes | Confirm that each family, item, location or asset has a unique reference. |
| Inconsistent units | Review units before creating stock, costs or recipes. |
| Incomplete relationships | Check referenced families, properties, customers, suppliers or locations. |
| Obsolete data | Separate initial loading, corrections and periodic updates. |

An import with inconsistent codes creates cleanup work in the catalog, planning and stock.

## Files

Files are used for documents, evidence, images and attachments for actions, tasks or designs. Use clear names so teams can find the correct file.

Some workflows require file permissions as well as functional permission. For example, uploading evidence may require file upload permission.

Saved files consume the storage included in the plan. If an upload exceeds the limit, Bold does not save the file. View your contract's usage and limit in **Control panel > Subscription > Plan**.

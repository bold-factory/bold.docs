**Boldy** is Bold's conversational assistant. It lets you look up information in natural language, summarize data and get guidance without navigating every menu.

## When to use Boldy

| Requirement | Example |
| --- | --- |
| Find data | `Which sales orders are pending this week?` |
| Summarize information | `Summarize delayed manufacturing orders.` |
| Understand a process | `Explain what projected stock means.` |
| Prepare a search | `Help me find maintenance work orders for the packaging machine.` |

Boldy responds with the context and permissions available to your user. If data is missing, it should ask for clarification or indicate what is missing.

## Conversations

A conversation preserves context. Use it to explore the same goal further. Create a new conversation when the topic changes or you do not want to carry earlier decisions forward.

| Good pattern | Why it helps |
| --- | --- |
| Specify the module | Avoids overly general answers. |
| Specify dates or status | Narrows the analysis. |
| Include codes, items, assets or locations | Reduces ambiguity. |
| Verify referenced records | Protects operational decisions. |

## Difference between conversation, tasks and automations

| Tool | Main use |
| --- | --- |
| Boldy | Quick, direct conversation with the personal assistant. |
| Tasks | One-off work with a status, files, tools, clarifications and credits. |
| Automations | Reusable configurations to repeat work manually or through triggers. |

Use Boldy to explore or ask questions. Create a task when work is long, needs files or should be audited. Configure an automation when you want to reuse the same instructions and permissions.

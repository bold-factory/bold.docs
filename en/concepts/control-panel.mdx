## Administrative access

User permissions protect Control panel actions. An integration key works differently: it currently has broad administrative access to the tenant and does not support configurable scopes.

<Warning>
  Treat each integration key as an administrative credential. Store it in a secrets manager, use a different key for each system and revoke it when it is no longer needed.
</Warning>

The Bold API reference is published by the Bold service at `https://api.bold-factory.com/docs`. Use it to browse endpoints, parameters, schemas, examples, and interactive tests.

<Card title="Open API documentation" icon="external-link" href="https://api.bold-factory.com/docs">
  Access the documentation published by Bold.
</Card>

## What it contains

- Public version endpoints.
- Path, query, and body parameters.
- Request and response schemas.
- Models and response codes.
- Interactive tests against the API environment.

## Before calling the API

You need a valid API key or session credential. For server-to-server integrations, create a key in **Control panel > Access > API keys** and send it in the `X-Api-Key` header.

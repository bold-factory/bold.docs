To define the process in Bold, create a simple **recipe** that generates an executable MO without modeling the entire manufacturing process yet. A recipe describes the operations, materials, and instructions needed to manufacture a product. See [Recipes and versions](/en/concepts/manufacturing/recipes-and-versions) for its complete structure.

Start with one main operation, the essential consumption, and a clear output of the finished item.

You can add more operations, inspections, restrictions, conditions, tools, and variants once you have validated this first walkthrough.

## Before you start

You need:

- a manufacturable family;
- a finished item associated with that family;
- the components you want to consume;
- a process and a resource compatible with the operation;
- permission to create and activate recipes.

## Define the process in Bold

<Steps>
  <Step title="Open recipes">
    Go to **Production > Recipes** and create a recipe for the chosen family.
  </Step>
  <Step title="Create an editable version">
    Use a new version to prepare the structure. Do not activate it until you have reviewed the operations, inputs, and outputs.
  </Step>
  <Step title="Add a main operation">
    Create an operation representing the main work, such as **Assembly**, **Mixing**, **Cutting**, or **Packaging**.
  </Step>
  <Step title="Associate the process">
    Select a process that can run on the resource you created. This lets the MO find compatible workstations.
  </Step>
  <Step title="Add inputs">
    Specify the components and the quantity consumed per unit manufactured. Use quantities that are easy to check in the first walkthrough.
  </Step>
  <Step title="Define the output">
    Check that the recipe produces the expected finished item. The MO uses this information to record production.
  </Step>
  <Step title="Activate the version">
    Activate the version when the structure is consistent. Only active versions are used to create new orders.
  </Step>
</Steps>

## What to include and what to leave out

| Element | First walkthrough | Later |
| --- | --- | --- |
| Operations | One main operation. | Several stages with dependencies. |
| Inputs | Essential components. | Formulas, variants, and consumption at specific moments. |
| Steps | Short instructions if they help the shop floor. | Detailed instructions for each stage. |
| Inspections | Only to check an essential requirement. | Additional quality inspections. |
| Restrictions | None if there is only one operation. | Partial, total, or non-blocking restrictions. |
| Tools | Only if required to execute the operation. | Fixtures, molds, and required characteristics. |

<Warning>
  If you add required inspections, make sure the team knows how to complete them in **work mode**. A required inspection can block an operation from starting or finishing.
</Warning>

## Quick check

Before creating the order, check that:

- the recipe version is active;
- the operation has a process;
- at least one resource is compatible with that process;
- the inputs use existing items;
- the output matches the finished item you will sell.

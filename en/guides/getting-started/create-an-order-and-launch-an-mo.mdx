The sales order makes the customer's need visible. The manufacturing request indicates what remains to be manufactured. The MO turns that need into executable operations.

This guide connects sales, planning, and manufacturing in a short example.

## Before you start

You need:

- a finished item configured as manufacturable;
- an active recipe for the product;
- an employee and a resource ready to execute the operation;
- a test customer or a real customer;
- permission to create orders, requests, and manufacturing orders.

## Create demand from the order

<Steps>
  <Step title="Create the order">
    Go to **Planning > Sales orders** and complete the general details: customer, customer order number, date, delivery instructions, and notes, where applicable.
  </Step>
  <Step title="Add the line">
    Select the requested item, enter the quantity, and set the delivery date.
  </Step>
  <Step title="Confirm the line">
    Confirm the line when you want it to generate demand. While it is a draft, it does not affect planning.
  </Step>
  <Step title="Review availability">
    Check available stock, planned supply, and the quantity still to be covered.
  </Step>
</Steps>

<Warning>
  Creating the order and confirming demand are separate actions. Demand is created when you confirm the order line.
</Warning>

## Turn demand into an MO

<Steps>
  <Step title="Review the need">
    Open planning or the operational view you use to review manufacturing needs. Find the item, quantity, and date from the order.
  </Step>
  <Step title="Create the manufacturing request">
    Turn the recommendation into a request. For a first test, you can also create a manual request with the same quantity and date as the order.
  </Step>
  <Step title="Open the request">
    Check the item, quantity, required date, and quantity pending assignment.
  </Step>
  <Step title="Create the MO">
    Generate a manufacturing order from the request. Select the active recipe and confirm the quantity you will manufacture.
  </Step>
  <Step title="Review the order">
    Check that the MO has operations, inputs, an output, a date, and a compatible resource if the process requires one.
  </Step>
</Steps>

## What should happen

| Action | Result |
| --- | --- |
| Confirm an order line | Generates demand for the manufactured item. |
| Create a request | Describes what remains to be manufactured and by when. |
| Create an MO | Copies the structure of the active recipe. |
| Review an operation | Helps you identify missing resources, dates, tools, or permissions. |

<Info>
  You can split a request into several MOs if you manufacture in lots or multiple batches. For the first walkthrough, create a single MO with the order quantity.
</Info>

## If you cannot create the MO

| Problem | What to check |
| --- | --- |
| No need appears | The order line is confirmed and the item is manufacturable. |
| You cannot create a request | Permissions and the item's procurement policy. |
| No recipe appears | The recipe belongs to the correct product and has an active version. |
| The operation cannot be planned | The process, compatible resource, tools, or restrictions. |

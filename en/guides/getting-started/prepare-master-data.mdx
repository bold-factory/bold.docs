Prepare only the data you need to complete the first walkthrough. The goal is to turn an order into an executable MO, without entering the company's entire operation.

Use a familiar product that is easy to recognize. Starting with an unusual case means resolving exceptions before validating the main workflow.

## Expected result

When you finish, you should have:

- a family for the product;
- a finished item associated with a family;
- the components you want to consume in the recipe;
- at least one operational employee;
- a process and a compatible production resource;
- a basic location if you will record consumption or production with stock.

## Create the minimum foundation

<Steps>
  <Step title="Create the family">
    Go to **Catalog > Families** and create the family for the finished item. Use a stable code and a descriptive name.
  </Step>
  <Step title="Create the finished item">
    Go to **Catalog > Items** and create the manufacturable item. Select the family created above. Set the procurement source to **Make**.
  </Step>
  <Step title="Create the components">
    Add the items the recipe will consume. For the first walkthrough, use a few components and simple quantities.
  </Step>
  <Step title="Create an operational employee">
    Go to **People > Employees** and create the person who will record shop floor work. Link a user if that person needs to sign in.
  </Step>
  <Step title="Create a process and resource">
    Create a process, such as **Assembly**, **Cutting**, or **Packaging**. Then create a workstation, machine, line, or work center that can execute it.
  </Step>
  <Step title="Create a basic location">
    Add an initial location if you will consume components or record produced stock. You can separate receiving, production, and dispatch areas later.
  </Step>
</Steps>

## Recommended decisions

| Decision | Recommendation for the first walkthrough |
| --- | --- |
| Family | Use a simple family with one variant. |
| Finished item | Mark it as manufacturable and use a familiar unit. |
| Components | Create only the materials whose consumption you want to see. |
| Lots | Leave them out unless traceability is essential. |
| Resource | Use a workstation or work center with a name the shop floor recognizes. |
| Employee | Create a real or test operational person the team can identify. |

<Tip>
  If you are unsure how to model a variant, first create a simple item. Correct the pattern before entering many similar families.
</Tip>

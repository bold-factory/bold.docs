## Recommended order

<Steps>
  <Step title="Define the goal">
    Decide whether you need to query, analyze, automate or review a completed task.
  </Step>
  <Step title="Choose the tool">
    Use reports to review metrics, Boldy for queries or one-off tasks, and automations for recurring work or work triggered by events.
  </Step>
  <Step title="Review permissions and data">
    Check that the user and automation can access the necessary modules.
  </Step>
  <Step title="Audit the result">
    Review history, credits, inputs used and actions performed.
  </Step>
</Steps>

## Choose a tool

| Need | Recommended tool |
| :-- | :-- |
| View consolidated metrics | Power BI reports. |
| Ask about data or status | Boldy. |
| Analyze a situation with context | Boldy. |
| Perform a one-off task | Boldy. |
| Schedule a periodic review | Automation. |

## Before you start

Response quality depends on available data. Keep the catalog, stock, manufacturing orders and work orders up to date before requesting operational analysis.

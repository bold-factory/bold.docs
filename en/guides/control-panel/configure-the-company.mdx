Use **Settings** to define settings shared across the organization. These values affect calculations, automations, generated codes, documents and the context used by AI.

## What you can configure

| Area | Use |
| --- | --- |
| Logo | Visually identifies the company wherever Bold supports corporate branding. |
| Company activity | Provides context to AI for more relevant responses. |
| Default lead time | Working days used when there is no specific lead time. |
| Time zone | Affects dates, times, schedules and automations. |
| Language | Defines the company locale from the available options. |
| Request cancellation | Controls what happens to associated orders when a manufacturing request is cancelled. |
| Manufacturing automations | Allow MOs to be generated or planned automatically. |
| Load provisioning | Requests materials before a load's planned date. |
| Code prefixes | Apply to codes generated by Bold. |

## Critical settings

<Warning>
  Change the time zone, prefixes and automations carefully. They can affect new records, schedules, integrations and date interpretation.
</Warning>

| Setting | What to review before changing |
| --- | --- |
| Time zone | Whether it matches the company's main operations. |
| Prefixes | Whether they conflict with codes already in use or external integrations. |
| Generate orders automatically | Whether planning and recipes are ready to create orders without manual review. |
| Plan orders automatically | Whether resources, shifts and priorities are well defined. |
| Provision loads automatically | Whether each load has a location, date and lines before entering the lead-time window. |
| Request cancellation | Whether you want to always block, always cancel or only cancel orders that have not started. |

## Update settings

<Steps>
  <Step title="Open Settings">
    Go to **Control panel > Settings**.
  </Step>
  <Step title="Review the logo and activity">
    Upload a logo in a recommended format (PNG or SVG) with a transparent background and describe the company's activity.
  </Step>
  <Step title="Adjust general values">
    In **Default lead time (business days)**, specify the working days the factory takes to deliver an order when the item has no specific lead time. For example, enter `5` if it usually takes five days. If you define the lead time for each item, you can leave the value at `0`.

    In **Time zone**, select the zone for the main plant or site. It affects work mode records, shifts, automations and date and time display.

    In **Language**, select the company locale from the available options.

    In **My operations source**, choose the criterion work mode uses to display pending operations to the employee identified on the tablet:

    - **Skills:** displays operations associated with the employee's skills, such as `Welding`.
    - **Usual workstations:** displays operations at the stations or machines to which they are usually assigned.
  </Step>
  <Step title="Define behavior when cancelling requests">
    Choose one of these options:

    - **Always block the linked orders:** MOs remain blocked until someone reviews the case. The block can be removed.
    - **Always cancel the linked orders:** MOs are cancelled and can no longer be executed.
    - **Cancel if not started; block if already started:** MOs without activity are cancelled, and those already started are blocked for review.
  </Step>
  <Step title="Automate MO planning">
    **Generate production orders automatically**

    Select the checkbox if you do not need the technical office to convert each request into an MO manually. Leave it cleared if you prefer to accumulate demand or review quantities before generating work.

    For example, for a request for 100 boards, Bold can generate the MO without waiting for a manager to release it manually. Its planning depends on the next setting.

    **Plan production orders automatically**

    Select the checkbox if you want Bold to plan new MOs automatically. Leave it cleared if you need to review each order before planning it.
  </Step>
  <Step title="Configure automatic provisioning">
    **Provision load orders automatically**

    Select the checkbox if you want Bold to request the movements needed to prepare a load order automatically. If you prefer to review each load before requesting materials, leave it cleared.

    For example, if a load includes 20 units stored at another location, Bold can request their transfer to the loading location when the configured lead time is reached.

    **Provisioning lead time (business days)**

    Enter the days the warehouse team needs to prepare or move material to the work area. The minimum value is `0`. With `0`, the load is provisioned on its planned date; with `1`, one working day earlier.

    The request reserves available stock at the loading location and creates [preparation movements](/en/concepts/warehouse/warehouse-movements) for the missing quantity.

    For example, with `1`, the request for a load planned for Tuesday can be generated one working day earlier.
  </Step>
  <Step title="Standardize prefixes">
    Prefixes are codes of up to four characters added before the sequential numeric identifiers generated by Bold. They help you recognize the document or entity type on labels, delivery notes and screens.

    **Usage recommendations:**

    - **Short and clear:** use abbreviations of two to four letters that the team recognizes.
    - **Stable:** avoid changing them once records exist to maintain consistency in searches and traceability.

    **Examples:**

    ```text
    ART -> Items
    OF  -> Manufacturing orders
    WO  -> Work orders
    ```
  </Step>
</Steps>

## Common problems

| Problem | What to review |
| --- | --- |
| New codes do not have the expected prefix | Review the configured prefix and whether the record was created before the change. |
| Automation times do not match expectations | Review the company time zone. |
| A cancellation does not allow associated orders to close | Review the request cancellation policy. |
| AI responds with little business context | Complete the company activity. |
| A load does not request materials automatically | Check that it is planned, has not already been requested and its date is within the lead-time window. |

Use this workflow to create an MO that does not originate from a sales order or production assistant recommendation.

In Bold, first create a **manufacturing request** and then turn it into an MO. The request records which item you need to manufacture, in what quantity, and by when. See [Manufacturing requests](/en/concepts/manufacturing/manufacturing-requests) to understand their relationship with orders.

Because the request is created manually, it does not include the demand context supplied by a sales order or assistant recommendation.

## Steps to follow

**Path:** **Production > Production requests > Add new request**

### 1. Complete the fields

**Item:** choose the item to manufacture. To turn the request into an MO later, the item must have an active recipe.

**Quantity:** enter how much to produce in the item's unit of measure, such as units, liters, or kilograms.

**Customer (optional):** link the request to a customer. The requester takes the customer's name and cannot be edited separately. MOs created from the request are linked to the same customer. You need permission to view customers.

**Requester (optional):** if you do not link a customer, indicate who originated the need, such as a department or internal reference. You can leave it empty.

**Notes (optional):** add observations for the shop floor team. You can also attach files from the editor if you have upload permission.

**Required date (optional):** enter when you need the item available.

**Firm:** select this option when the required date is a strict commitment. If left unchecked, the request is considered tentative.

**Code (optional):** an internal identifier to reference the request. It can be the customer's sales order number or a code generated by Bold.

### 2. Create the MO

Save the request and use the rocket icon action to create the MO. The order turns the recorded need into work you can plan and execute on the shop floor.

Warehouse management lets you know where materials are, how they arrive, how they leave, and which movements explain each change. This data connects physical stock with purchasing, sales, planning, manufacturing, and costs.

## What changes stock

| Action | Effect |
| --- | --- |
| Receive a purchase order | Increases physical stock. |
| Ship materials | Reduces physical stock. |
| Move stock | Changes location or package while preserving the lot and total quantity. |
| Adjust stock | Corrects an individual discrepancy. |
| Take a stock count | Reconciles according to the physical count. |
| Consume or produce | Updates stock from manufacturing. |
| Execute a warehouse movement | Transfers materials through audited pick-ups and deliveries. |
| Complete a load order | Dispatches its shipments and reduces stock at the loading location. |

## Before you start

Define locations and decide which items require lots. If you work with supplier documents, prepare their item references to help associate data when scanning delivery notes.

A sales order records a commitment to a customer. It generates demand when you confirm its lines and can be delivered in one or more shipments.

## Create a sales order

**Path:** **Planning > Sales orders**

### Add an order

**Order no. (optional):** you can use your company's current naming convention. If you leave it empty, Bold assigns a code.

**Customer order no. (optional):** record the reference the customer uses to identify the order.

**Customer:** select one of the registered customers.

**Order date (optional):** specify when the order was agreed.

**Short description (optional):** add a short name that helps you recognize the order in lists.

**Delivery instructions (optional):** specify requirements to consider when preparing or delivering the order.

**Notes (optional):** leave internal comments. From the editor, you can attach quotations, technical sheets or drawings if you have permission to upload files.

### Add lines

Add one line for each requested item. The order must contain at least one line.

**Item:** select the item requested by the customer from the catalog.

**Quantity:** units demanded.

**Requested delivery date:** the day the customer requests to receive the item. If you select **Committed**, the same date is also recorded as the committed delivery date.

If the order lines that are not delivered or cancelled share the same date, Bold suggests it when you add a new line. If they share the committed date, Bold also selects **Committed**. You can change the suggestion before adding the line.

**Notes:** use the line note to give instructions for an item without affecting the rest of the order. For example, you can specify a particular label or pallet arrangement.

From the notes editor, you can attach documents, photos or drawings for the line if you have permission to upload files.

**Status:** **Confirmed** or **Draft**. A confirmed line generates demand and is included in planning. A draft line does not generate demand and allows you to change the item, quantity and procurement mode.

**Supply:** select **Make to stock** to cover demand with planned stock, or **Make to order** to trigger purchasing or manufacturing from a confirmed line.

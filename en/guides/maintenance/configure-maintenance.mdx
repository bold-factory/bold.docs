## Create an asset

**Path:** **Maintenance > Assets**

On the assets screen, you can view resources created in **Production** and register other equipment or physical spaces that need maintenance.

For example, register cutting machines, industrial ovens, assembly lines, or packaging areas.

To register an asset, complete these fields:

- **Asset type:** select the class of element you will maintain.
- **Name:** assign a descriptive name the shop floor team can recognize.
- **Location or hierarchy:** indicate whether the asset is in an area, plant, or warehouse, or is part of larger equipment.
- **Identification code:** enter the existing internal code. If you do not have one, leave the field blank for the system to generate it.
- **Additional data:** add information such as manufacturer, model, or serial number.

## Create actions

**Path:** **Maintenance > Actions > Add new**

Define reusable tasks you can add to maintenance work.

For example, create actions to change a blade, clean filters, or replace belts.

Specify the approximate execution time and the type of result the operator must record.

If you choose **Selection**, enter the response options, one per line. The technician chooses one when completing the action. If you choose **Signature**, the technician draws their signature on the screen.

Options are copied to the work order when you add the action. If you later change the definition, actions already on a work order retain their previous options.

## Create causes

**Path:** **Maintenance > Causes > Add new**

Define reasons requiring an intervention and use consistent names.

This simplifies daily recording and helps identify recurring failures.

For example, create causes for belt wear, electrical faults, or dirt.

Once you create the cause, assign the usual actions for resolving that type of problem.

For example, if you always replace worn belts, associate that action with the cause so it is planned.

From the **Actions** column in each list, open a record to view its details or change it.
